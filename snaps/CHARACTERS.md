# Charaktere für beide Snap-Serien

Die Figuren basieren auf Personen, die in den bereits generierten Snaps vorkommen. Für jede Figur einmal ein
Referenzbild erzeugen (Prompt ganz unten), das Bild in Flow bei jedem neuen Snap als Referenz anhängen und im
Prompt mit `[Name] from the attached reference photo (same face, same hair)` ansprechen.
Der Kameramann („ich") ist in beiden Welten nie zu sehen und spricht nie (Voiceover kommt später).

## Referenzbild pro Figur erzeugen (Nano Banana 2, Snap-Bild als Referenz anhängen)

```
Using the attached photo only as the reference for this person's face and hair, generate a clear, sharp character reference sheet of the same person: a front-facing head-and-shoulders portrait on the left and a full-body standing shot on the right, side by side, on a plain light grey background in soft natural daylight. Same face, same hair, same freckles and features, neutral friendly expression, wearing [OUTFIT]. Realistic photo, no text, no watermark.
```

Outfit je Figur: Wizarding World = „black school robe with [house colour] lining, white shirt, grey jumper and [colour] striped tie"; Pokémon = Kleidung aus der Tabelle.

## In jedem neuen Snap-Prompt

Referenzbilder der vorkommenden Figuren anhängen und im Prompt schreiben, z. B.:
`Very close on the left, Theo from the attached reference photo (same face, same hair), ...`
Maximal zwei bis drei Figuren pro Bild, sonst mischt Flow die Gesichter.
