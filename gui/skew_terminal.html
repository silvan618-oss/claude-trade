So bringst du es zum Laufen

einmal ~30 Minuten

  1. Python holen

    Version 3.10 oder neuer, von python.org. Beim Windows-Installer den Haken bei „Add Python to PATH“ setzen.

  2. Projekt herunterladen und einrichten

    Terminal öffnen (macOS: Terminal, Windows: PowerShell), Zeile für Zeile eingeben.

    # Projekt holen
git clone https://github.com/silvan618-oss/claude-trade
cd claude-trade

# abgeschottete Umgebung + Pakete
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

  3. Ersten Lauf machen

    Braucht keine Keys, keine Anmeldung, kein Datenabo. Erfundene, aber realistische Zahlen — damit du siehst, wie das Board aussieht.

    python -m bot.skew_map --demo

  4. Dein eigenes Blatt anlegen

    Schreibt eine leere Tabelle mit den richtigen Spalten. Trag 15–25 Namen ein, die du ohnehin verfolgst.

    python -m bot.skew_map --template blatt.csv

  5. Einmal pro Woche ausfüllen

    Bei deinem Broker die Optionskette der Aktie öffnen, eine Monatsexpiry rund 45 Tage in der Zukunft wählen — und immer dieselbe Regel für alle Namen. Dann drei Zahlen abtippen:

    ATM-IV = implizite Volatilität beim Strike, der dem Kurs am nächsten liegt. Put-IV = beim Put mit Delta ≈ 0.25. Call-IV = beim Call mit Delta ≈ 0.25. Dazu die Monatsrendite und das relative Volumen aus einem beliebigen kostenlosen Screener. Rund 20 Minuten für 20 Namen.

  6. Auswerten

    Gleicher Befehl, jede Woche. Jeder Lauf legt zusätzlich skew_history/JJJJ-MM-TT.json ab.

    python -m bot.skew_map --csv blatt.csv

  7. Hier hochladen

    Oben rechts auf Snapshot laden und die JSON-Datei aus skew_history/ auswählen. Dann steht dein eigenes Board auf dieser Seite — Karte, Sätze, Sektoren, alles. Die Datei verlässt deinen Rechner nicht.

Die vier Quadranten

einmal festgelegt

Skew auf die eine Achse, Monatsrendite auf die andere. Jeder Name landet in genau einer Box — und was die Box bedeutet, wird vorher entschieden, nicht um 16 Uhr an einem roten Tag.

Contrarian Bid ist die einzige Box, in der zwei Quellen uneins sind: Der Kurs fällt, aber jemand zahlt trotzdem für Aufwärts. Deshalb ist sie die einzige, die eine Untersuchung wert ist — und deshalb ist sie nie voll.

Zeigen Kurs und Positionierung in dieselbe Richtung, hast du nichts gelernt, was der Chart nicht auch sagt.

Warum manche Namen hohl sind

die Qualitätsprüfungen

Ein einzelner kaputter Kurs in der Optionskette kann einen ganzen Namen umdrehen. Im Originaltext druckte das System einen Versorger bei −1.43 — richtig waren etwa +0.20 — und dieser eine Name zog die Validierung von 0.90 auf 0.14.

Deshalb: ein Deckel, über dem die Zahl als kaputt gilt, und eine Mindestgröße für die Optionskette. Wer durchfällt, wird hohl gezeichnet und namentlich genannt statt still gelöscht. Ein System, das verschweigt, was es nicht abdecken konnte, verschweigt die Größe seines eigenen blinden Flecks.

Was diese Ebene kann: Sie sagt dir, welche Namen heute eine Untersuchung wert sind, und warum.

Was sie nicht kann: das Level, den Einstieg, die Invalidierung, den Zeitpunkt. Eine Shortlist ist kein Trade. Genau in dieser Lücke verliert man Geld mit richtigen Ideen — man liegt richtig beim welchem Namen und falsch beim wo und wann.

Nach der Methode aus „Build Your Own Skew Map“ (berttrading). Optionsdaten sind unsauber, jede Zahl hier ist eine Modellentscheidung. Bildungszwecke — keine Anlageberatung, keine Kaufempfehlung.
